# 花掛印刷・記録アプリ（Paython版）

Excel VBAで作られていた「氏名・金額の記録＋印刷」を、Excelなしで動く
Windowsアプリ（Python版）に移植したものです。

## 構成

| ファイル | 役割 |
|---|---|
| `main.py` | メイン画面（Tkinter）。①記録して印刷 ②再印刷 ③当日集計 |
| `db.py` | データ保存（CSV、`hanacho.csv` が自動生成されます） |
| `hanacho.csv` | データ保存用CSVアフィル　が自動生成されます） |
| `printing.py` | 縦書きレシート画像の生成＋プリンタへの送信 |
| `kanji.py` | 金額の大字（壱・弐・参…）変換 |
| `requirements.txt` | 必要なPythonパッケージ |
| `花掛印刷・記録アプリ_説明書Paython版10.pdf` | インストール・使用説明書 |

元のExcelの「データ」シートと同じ列構成（ブロック／班／氏名／最新金額／
最新日付／過去金額／過去日付／印刷日／印刷状態）でCSVに保存するので、
考え方はそのまま引き継いでいます。データは最大でも数百件程度を想定した
シンプルな全件読み書き方式です。`hanacho.csv` は utf-8-sig（BOM付き）
形式なので、Excelでダブルクリックしてそのまま開いて中身を確認・修正
できます（Excelで開いたまま保存すると列の並びが変わる可能性があるので、
編集する場合は念のためコピーを取ってから行ってください）。

## 動かし方（開発・確認用）

1. Python 3.10以降をインストール（[python.org](https://www.python.org/) からWindows版を取得。
   インストール時に「Add python.exe to PATH」にチェックを入れてください）
2. このフォルダで以下を実行し、必要なライブラリを入れます。

   ```
   pip install -r requirements.txt
   ```

3. アプリを起動します。

   ```
   python main.py
   ```

## 印刷プレビューでの微調整

「①記録して印刷」「②再印刷」を押すと出てくるプレビュー画面で、以下を
その場でスライダーを動かしながら確認できます。

- 氏名／金額それぞれの「高さ(%)」…用紙の縦の長さに対する割合。桁数や
  文字数が変わっても、この割合になるようフォントサイズが自動計算されます
  （デフォルトは氏名30%・金額92%＝ほぼ用紙いっぱい）
- 氏名／金額それぞれの左右位置・下端位置（デフォルトは氏名が左、金額が右）
- 文字の間隔

「印刷する」を押すとその時の設定が `layout_settings.json` に自動保存され、
次回起動時もその設定が最初から使われます。コードを直接編集する必要は
基本的にありません。

※ 以前のバージョンで一度「印刷する」を押して`layout_settings.json`が
作られている場合、そのファイルを削除してから起動すると新しいデフォルト
（氏名30%・金額92%、氏名=左／金額=右）で始められます。

## 縦書きフォントについて

`printing.py` の `FONT_CANDIDATES` に、元のExcelで使っていた
「HG行書体」を優先的に探すようにしてあります。ただしWindowsのバージョンに
よって実際のファイル名（`HGGYOSOTF.ttc` など）が違う場合があるので、

1. Windowsの「設定」→「フォント」から実際のフォント名を確認する
2. `C:\Windows\Fonts\` の中の該当ファイル名を確認する

のいずれかで正しいパスを調べ、`FONT_CANDIDATES` の一番上に追記して
ください。見つからない場合は自動的に代替フォント（明朝体）を使います。

## 実際の印刷について

印刷は `pywin32` のプリンタAPIを使って直接プリンタへ画像を送ります。
開発中の見た目確認は「印刷プレビュー」画面（アプリ内のポップアップ）
だけで行えます。プリンタの向き・給紙方法などは、Windowsの
「プリンターのプロパティ」側で調整してください。

## .exe化して他の人にも配れるようにする

役員の方など、Pythonを入れていない人のPCでも使えるように、
`PyInstaller` で単独の実行ファイルにまとめられます。

```
pip install pyinstaller
pyinstaller --onefile --windowed --name "町会花代記録" main.py
```

- `--windowed` … 黒いコンソール画面を出さずに起動する
- 完成した `.exe` は `dist` フォルダの中にできます
- `hanacho.csv`（データファイル）は `.exe` と同じフォルダに作られるので、
  配布時は `.exe` を置くフォルダごとバックアップを取るようにしてください
  （CSVはテキストなので、こまめにコピーを取っておけば万一の際も
  中身を目で見て復旧できます）
